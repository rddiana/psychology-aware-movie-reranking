# External derived artifact

`kion_reward_item_features.csv` is a compact, derived catalogue-feature snapshot used by the notebooks. It replaces the unreadable compressed payload that was previously embedded directly in notebook cells, but is not published because it is derived from KION data.

Copy it from the private [`reward_model_v1`](https://drive.google.com/drive/folders/1pHZLh4PKdwkR1Jo3vywG0SaezEOeO6ft) run into this directory before executing notebooks 02–06. Expected size and SHA-256 are recorded in [`manifest.json`](manifest.json).
